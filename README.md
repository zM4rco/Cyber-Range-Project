# Cyber-Range-Project

Hi, welcome to my Cyber Range Project.

What was the purpose of this project?

To create a network security architecture that consists of the three components (confidentiality, integrity and availability) from the CIA Triad model.

Why?

With many data breaches and companies being hacked nowadays, the project aims to build a high level network security architecture that consists of data integrity protection and high availability to help businesses protect their data and ensure that their systems are constantly accessible for their users.

When?

It was originally developed in 2022 as part of my tertiary studies and later uploaded to GitHub for portfolio purposes.
